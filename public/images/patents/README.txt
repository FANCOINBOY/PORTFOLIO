Place your granted patent PNG files in this folder with the exact names below so the website can display them automatically:

Required filenames (PNG or JPG accepted):

1) patent-granted-1.png or patent-granted-1.jpg  -> shown for "Processor Magnifier Module" (Design No. 486360-001)
2) patent-granted-2.png or patent-granted-2.jpg  -> shown for "Multifunctional Wireless-Enabled Hairband System" (Design No. 469300-001)

How to add the images:

- Save the two certificate images you uploaded here in the project as the filenames above.
- Recommended: export as PNG, maximum width 1920px, and compress to keep each file under ~1MB for faster loading.

After adding the files the site will automatically render them in the "Patents and Innovations" section.

If an image does not appear, run the dev server and check the browser console for 404 requests to `/images/patents/<filename>`.
